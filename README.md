## Svar på teorifrågor om Git

**Vad är skillnaden mellan git add och git commit?**
git add innebär att alla ändringar som gjorts förbereds, de samlas ihop. git commit innebär att en permanent sparning sker, som ett orginal. 

**Varför använder man branches istället för att jobba direkt i main?**
För att inte förstöra orginalet, branchen blir som ett kladdpapper där man kan testa och prova sig fram utan att påverka orginalkoden. 

**Vad händer rent praktiskt när man gör en merge?**
De ändringar som gjorts i branchen slås ihop med orginalfilen. 

**Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?**
På github sparas koden och filerna, netlify tar den koden och bygger / läser om den till en riktig hemsida som vemsomhelst kan besöka och använda. 

**Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?**
